        模型

          「添加」会把输入的名称放进该提供方的列表； 点击列表里的模型即可使用它。

          无论你用什么语言写，代理都用这种语言 回答。它也会让模型用这种语言思考，这在有些模型上有效、有些上无效——回答一定 会跟着变，推理过程不一定。

          图片

          每个回合可以有一张图片，由这个模型来描述，描述内容成为你的消息——主模型永远 收不到图片。它有自己的端点、密钥和模型，因为读截图和写代码是不同的选择，而 一张涉及隐私的照片正适合交给本地模型。端点或模型留空即关闭图片功能：那时图片 按钮会拒绝并说明该设置什么。这里的内容不归 测试连接 测试——按图片 按钮才试得到。

          这是上限，不是开销：描述花掉的是模型写出来的量，与给了多少余量无关。推理模型 会在写出任何东西之前就花掉它，所以给得太少得到的是空回答而不是短 回答——一张手机截图给 1500 就太少。留空表示用默认值。

          用这些值向提供方发一个极小的请求。不会保存任何东西。
