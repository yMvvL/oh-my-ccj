# 它是什么，以及它不是什么

一份诚实的对照表。这一页存在的理由是：一个代理工具最容易在**边界**上撒谎——它可以列出二十项能力，而真正
决定你能不能信任它的是它**不做**的那几件，以及每一件不做的事对应的代价。

**先说三件真正核过、别处找不到的事**（2026-09 挨个核过 Claude Code、Codex、Aider、Cline 的官方文档之后）：

1. **不要密钥也跑得起来。** `--demo` 自带一个脚本化的提供方：不要账号、不要网络、不要 API key，就能把一个
   回合、工具调用和审批提示完整走一遍。四家的文档都要求账号，或者自备一个 OpenAI 兼容端点。
2. **一个 fat jar 同时是 CLI 和网页控制台。** 没有前端构建产物、没有安装器、没有账号、没有云：`java -jar
   ccj.jar` 之后,手机和桌面说的是**同一份本地文件**。
3. **每条主张都带着它的测量结果。** CHANGELOG 里每个条目都写着测到了什么、代价是什么、什么**没有**验证；
   `docs/PERF.md` 里有一个被量掉并**否掉**的优化；收据（`/receipt`）会把「这一轮哪些事没有验证」直接交给你。

**也不能当卖点的两件事**：主模型从不看图像（独立视觉模型写文本描述——这是绕开限制的取舍，能力上更弱），
以及中文单语界面（这是事实，不是选择）。

## 对照：这些是主流都有的

这一节的意义是**防止把重做当成创新**。下表的口径是 2026-09 挨个读四家官方文档得到的结论。

| 常见的卖点 | 现状 | 来源 |
|---|---|---|
| 检查点与回退 | Claude Code 每回合一个检查点、保留 100 个、`/rewind`;Cline 同义 | 对端官方文档，2026-09 核对 |
| 细粒度权限规则（allow/ask/deny、通配、按仓库持久化、面板） | Claude Code 的 `/permissions` 比这里的 `approvals.json` 更全 | 同上 |
| 沙箱 | 主流有（Claude Code 的 sandboxing、Codex 的 sandbox/execpolicy）；这里**刻意没有** | 同上 |
| 编辑后自动跑检查 | Aider 默认 lint+test、Claude Code 的 PostToolUse hook | 同上 |
| 网页 / 手机端 | Claude Code 有 web 与手机 App;Cline 有桌面 App 与 telegram/slack 接入 | 同上 |
| 花费上限 | Claude Code 的 `--max-budget-usd` 与 workspace spend limit;Aider 的 `/cost` | 同上 |
| MCP（双向） | Claude Code、Codex 都既做客户端也做服务器 | 同上，2026-10 复核 |
| 会话导出与分享 | 主流把会话放在云上、按账号走，导出多半是「分享一个链接」 | **未核实**（链接形态的产品特性变化快） |

**这一版没有附链接**，而且这是刻意的：核对是在对端文档里做的，而把链接抄进这里意味着我在一个没有网络的
环境里声称它们仍然有效。需要链接的话，按「产品名 + 功能名」自己再核一遍——这也正是你自己该做的事。

## 代价：不做那几件，换来的是什么

每一条都是读者**为了决定是否信任这个工具**所需要的取舍，不是道歉。

| 不做 | 意味着 | 换来 |
|---|---|---|
| **没有沙箱** | 审批是唯一的护栏，`--yolo` 会把它整个拿掉；`bash` 以你的身份、带着你的环境运行 | 一个下午能读完的运行时：没有容器编排、没有挂载策略、没有「看起来被隔离了」的错觉 |
| **不换算货币** | 侧栏显示 token 与缓存命中率，**不显示钱** | 一张价目表是一种不打招呼就会变的假设；token 是事实，价目表是假设 |
| **图片是单向的** | 主模型看到的是视觉模型写的**描述**，不是像素；单个 8 MB，一次一张 | 线上格式、渲染器、压缩步骤都不必长出图像分支 |
| **中文单语界面**（现在） | 英文读者只能读英文文档，界面是中文 | 量出来的成本是**网页 580 条 + 服务端 1067 条**字符串，而半翻的界面比单语更糟——英文按钮配中文报错，而报错恰恰是最需要看懂的东西 |
| **Windows 未验证** | 机制就位（shell 可配置、`ccj.cmd`），但**没有人**在真 Windows 上跑过 | 不在文档里写「支持」；一个没被验证的平台是一条负债，不是一项能力 |
| **每个会话一次只跑一个回合** | 同一工作区里多个对话的工具之间没有先后顺序（等同开两个终端） | 转录是一份「发生了什么」的记录；两个写入者的顺序未知，就不是记录 |
| **会话文件无上限增长** | 文件就是记录，不自动裁剪 | 内容放不进上下文预算时是**省略**（请求的投影），不是删除 |

## 它有多大（随时可核的数字）

| | |
|---|---|
| 主代码 | **27.9k 行 / 117 个文件 / 14 个包** |
| 测试 | **899 个用例 / 95 个类** + 2.5k 行 node 用例（含一个真浏览器） |
| 前端 | 9.0k 行原生 `app.js` / `style.css` / `index.html`，无框架、无构建步骤 |
| 运行时依赖 | **1 个**（`jackson-databind`) |
| 文档 | 4.5k 行，其中三份是测量记录：`PERF.md`（开销）、`EVAL.md`（评测）、`RETRIEVAL.md`（检索质量） |
| 覆盖率 | 行 **84.7%**、分支 **72.1%**（JaCoCo，一份报告而不是一道门；两个垫底的包是 `cli` 与 `ui`——交互路径，见 [CONTRIBUTING](../CONTRIBUTING.md）） |

| 包 | 文件 | 行数 | 一句话 |
|---|---|---|---|
| `core/` | 40 | 6.4k | 契约：循环、消息、预算、审批规则、收据 |
| `web/` | 10 | 5.2k | 同一个循环在 HTTP 后面：SSE、审批握手、单页控制台 |
| `tool/` | 15 | 3.6k | 文件系统、shell、网络、检索；每个都带手写 schema |
| `provider/` | 13 | 3.6k | 四种线路协议 + SSE 解码 + 重试 + 嵌入端点 + 闸门 |
| `cli/` | 3 | 2.1k | 参数解析、装配、REPL、退出码（唯一 `System.exit` 的地方） |
| `session/` | 8 | 2.0k | JSONL 会话、世代文件、附件、检查点、缩略图 |
| `mcp/` | 5 | 1.0k | 协议的**两半**：客户端与服务器 |
| `obs/` | 6 | 0.8k | 指标、span 树、装饰式观察者 |
| `retrieval/` | 5 | 0.7k | 切块、指纹、向量表、索引 |
| `eval/` | 4 | 0.7k | 任务、脚本化模型、评分、报告 |
| 其余（`ui` `demo` `workspace` `export`） | 8 | 1.8k | 终端渲染与二维码编码、离线替身、工作区注册表、导出 |

**「一个下午能读完」是这个项目最贵的一条主张**，而它现在的意思是：上面那张表里最大的一栏是 6.0k 行（39 个
文件，平均 150 行），而全树只有一个运行时依赖。数字会随改动漂移，所以它们在 `CONTRIBUTING.md` 里也有一份，
并且每次大改都重新数一遍。
